# Neural-network-and-Deep-learning
convolution operations, CNN architectures, transfer learning, and fine-tuning pretrained models.
The assignment covers:

Convolution, padding, and stride
CNN architectures
Representation learning
Transfer learning
Fine-tuning
Implementing 2-D convolution from scratch
Comparing frozen feature extraction and fine-tuning 
The first programming task demonstrates how 2-D convolution can be implemented from scratch using NumPy. The second programming task compares using a pretrained CNN as a frozen feature extractor with fine-tuning part of the pretrained network.

Freezing layers reduces the number of trainable parameters and generally reduces training requirements. Fine-tuning allows the pretrained model to adapt some of its learned features to the new dataset.

The experimental results provide a practical comparison of training time, trainable parameters, and accuracy between the two approaches.
